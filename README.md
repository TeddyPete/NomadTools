# ZeroAVTools

Field tools for AV work on the [M5Stack CardputerZero](https://docs.m5stack.com/en/CardputerZero),
a pocket Raspberry Pi CM0 Linux handheld with HDMI out, a camera, a mic and a keyboard.

| Tool | Folder | Status |
| --- | --- | --- |
| AV tester: HDMI test patterns, tones, lip-sync meter | [`av-tester/`](av-tester/) | In progress |
| Network tools | (planned) | Not started |

Each tool lives in its own folder with its own README and install steps.
